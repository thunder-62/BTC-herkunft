# Testkopie des Regelwerks

Eingefrorene Kopie von `btc-regeln/` (Stand 29.09.2026) für die Tests. Die Tests prüfen
Texte und Zuordnungen gegen diese Kopie, damit fachliche Änderungen an `btc-regeln/` durch
die steuerliche Prüfung die Tests nicht brechen. Die echten Dateien prüft
`tests/test_regelwerk.py::test_repository_rules_are_valid` nur auf Gültigkeit (REGELWERK.md
Abschnitt 5). Nicht an neue Rechtslagen anpassen — nur bei Schemaänderungen.
